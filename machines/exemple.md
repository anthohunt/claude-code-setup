# Partie machine : mon-ordi (modèle)

Importée par le CLAUDE.md global via `~/.claude-machine.md` (lien vers ce fichier, posé par `provisionner.py`).
Ne contient que ce qui est propre à CET ordinateur.

- Appareil : portable de travail, Linux, shell bash, utilisateur `moi`.
- Dossiers de travail : skills `~/claude-config/skills`, mods `~/claude-config/mods`, mémoire `~/claude-config/memoire`.
- Outils installés : `git`, `gh`, `docker`, `node`, `python3`.
- Particularités : aucune limite de processeur ; la sauvegarde tourne chaque nuit.
